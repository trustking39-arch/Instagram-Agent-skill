# Instagram Agent Skill

This skill helps Jarvis plan original Instagram video content: it can develop
Reel concepts, hooks, scripts, shot lists, captions, calls to action, and a
review-ready publishing calendar.

It cannot guarantee that a video will go viral. It does not publish content
automatically or support five posts per hour. Every post must be reviewed and
approved by the account owner. Publishing requires a separately configured,
authorized official integration; none is included in this repository.

See [SKILL.md](SKILL.md) for the agent workflow and safety requirements.
